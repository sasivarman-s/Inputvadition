# InputVadition

A responsive user login form built with **HTML, CSS, JavaScript, and Tailwind CSS**, focused on practicing client-side form input validation and interactive user feedback.

## 🚀 Features

* User login form interface
* Client-side input validation using JavaScript
* Interactive form feedback
* Responsive user interface
* Clean and simple design
* Practice project for JavaScript DOM manipulation and form handling

## 🛠️ Technologies Used

* **HTML5** – Structure and semantic markup
* **CSS3** – Styling and layout
* **JavaScript** – Form validation and user interactions
* **Tailwind CSS** – Utility-first styling configuration

## 📂 Project Structure

```text
Inputvadition/
│
├── index.html          # Main login form
├── style.css           # Custom styles
├── script.js           # JavaScript validation logic
├── tailwind.config.js  # Tailwind CSS configuration
└── WEB/                # Web-related project files
```

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sasivarman-s/Inputvadition.git
```

### 2. Navigate to the project directory

```bash
cd Inputvadition
```

### 3. Run the project

Since this is a frontend project, you can open `index.html` directly in your browser.

For a better development experience, you can also use the **Live Server** extension in Visual Studio Code.
